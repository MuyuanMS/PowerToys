Falls back to cursor-based selection if the foreground window is absent or not manually processable.  ```cpp // Before auto workArea = m_workAreaConfiguration.GetWorkAreaFromCursor();  // After const auto foregroundWindow = GetForegroundWindow(); WorkArea* workArea = nullptr; if (foregroundWindow) {     workArea = m_workAreaConfiguration.GetWorkAreaFromWindow(foregroundWindow); } else {     workArea = m_workAreaConfiguration.GetWorkAreaFromCursor(); } ```  `GetWorkAreaFromWindow` already existed and correctly handles both the span-across-monitors case and per-monitor mode.  ## PR Checklist  - [ ] Closes: #xxx - [ ] **Communication:** I've discussed this with core contributors already.
