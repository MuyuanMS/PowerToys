VISUAL IMAGE TRANSFORM / ROTATE 90 DEGREES
  Input: Images\sample-arrow.png (the original blue arrow).
  Advanced Paste: open it, copy the IMAGE rather than just its file path,
  run Rotate image 90 degrees, and paste into a scratch image-capable app.
  Alternative: select the PNG in Explorer and run the same script;
  open the newly exported PNG.
  Before: blue arrow points RIGHT, 320 x 180.
  After: blue arrow points DOWN, 180 x 320.
  Always 90 degrees clockwise. No angle parameter. Original stays unchanged.

FILE EXPLORER / ANY FILE TYPE
  Open General-files and select all THREE files:
    Project brief.txt, North.csv, Meeting notes.png.
  Run Create a file summary; open the newly exported HTML.
  Show three different file types, names, sizes and SHA-256 fingerprints.
  No format-specific application, parameters or network required.
  For a faster version, select just Project brief.txt.
  Works with other locally available regular files too, including PDFs,
  Office files and extensionless files; it reads bytes, not document formats.
  Demo bounds: 1-20 files, up to 256 MB in total.
